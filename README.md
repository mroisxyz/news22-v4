## Run it

Node 22+ executes the TypeScript entry directly:

```bash
MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```

`main.ts` recursively creates the output directory, copies `entry.png` from its own directory into it, and logs the copied byte size. If `MAKEFUN_OUTPUT_DIR` is unset it defaults to `/output`.
